# Наманган туризм — ресторан ва савдо дўконлари боти

Тайёр бот дастури. Telegram аккаунтида бот рўйхатдан ўтказилмагунча, токен ва қабул қилувчи гуруҳ уланмагунча ишга тушмайди.

## Бот нима қилади?

- Ўзбек кириллицада 11 босқичли сўровнома ўтказади.
- Ресторан, кафе, савдо дўкони ёки бошқа объект турини сўрайди.
- Ном, қисқача маълумот, туман/шаҳар, манзил ва мўлжални йиғади.
- Telegram локацияси ёки Google Maps / Yandex Maps ҳаволасини қабул қилади.
- Телефон, иш вақти, масъул шахс, ижтимоий тармоқ саҳифасини сўрайди.
- 5–6 та турли фотосуратни алоҳида ёки альбом шаклида қабул қилади.
- Юборишдан олдин маълумотларни текшириш учун кўрсатади.
- «Бошқармага юбориш» босилганда маълумотларни ёпиқ гуруҳга юборади: матн, расмлар альбоми ва Telegram локацияси. Харита ҳаволаси юборилган бўлса, ҳавола матнда келади.
- Узилиб қолган сўровномани сақлайди. /start → «Давом эттириш» билан давом этилади.
- Қабул қилувчи гуруҳга юборишда хато бўлса, навбатни сақлаб, қайта уринади. /status юбориш ҳолатини кўрсатади.

## Windows компьютерида ишга тушириш

1. ZIP файлни очиб, папкага чиқаринг.
2. Python 3.10 ёки ундан янги версияни ўрнатинг. Ўрнатишда **Add Python to PATH**ни белгиланг. Қўшимча Python пакетлари талаб қилинмайди.
3. Telegramда расмий **@BotFather**ни очинг: https://t.me/BotFather . `/newbot` буйруғи орқали бот яратинг. Масалан, ном: **Наманган туризм | Объектлар сўровномаси**. Username `bot` билан тугаши керак ва бўш бўлиши шарт; масалан `NamanganTourismInfoBot` — мавжудлиги текширилмаган намуна.
4. BotFather берган токенни олинг. **setup.bat**ни очинг ва токенни киритинг. Токен экранда кўринмайди. Гуруҳ ID рақамини ҳали билмасангиз, Enter босинг. Токенни бошқаларга юборманг.
5. Туризм бошқармаси масъуллари учун ёпиқ Telegram гуруҳи очинг ва янги ботни қўшинг. Ботга матн, фото ва локация юбориш рухсатини беринг. Оддий гуруҳда бунинг учун администратор ҳуқуқи шарт эмас.
6. **start.bat**ни очинг. Гуруҳга `/chatid@СизнингБотUsername` буйруғини ёзинг. Бот гуруҳ ID рақамини кўрсатади (одатда манфий рақам).
7. Ботнинг ойнасида **Ctrl+C** босиб тўхтатинг. **setup.bat**ни қайта очинг, токенни ва гуруҳ ID рақамини киритинг; мавжуд созламаларни алмаштириш учун `yes` деб ёзинг.
8. **start.bat**ни қайта очинг. Ботнинг шахсий чатига кириб `/start` юборинг ва синов сўровномасини тўлдиринг. Матн, 5–6 та фото ва локация гуруҳга келганини текширинг.

**Компьютер ўчса, интернет узилса ёки дастур ойнаси ёпилса, бот ишламайди.** Доимий ишлаши учун интернетга уланган серверда ишлатинг.

## Серверда ишга тушириш

Тўпламни серверга кўчиринг. Созлаш: `python3 bot.py --setup`. Ишга тушириш: `python3 bot.py`.

Docker мавжуд бўлса, `.env`га токен ва гуруҳ ID рақамини киритиб, папкада `docker compose up -d --build`ни бажаринг. Ҳолат: `docker compose logs --tail 30 bot`.

Ботнинг битта нусхасини ишлатинг. У long polling усулидан фойдаланади; ишга тушганда шу токенга боғланган аввалги webhookни ўчиради. Янги бот учун алоҳида токен ишлатинг.

## Бошқариш тугмалари

| Тугма / буйруқ | Вазифаси |
|---|---|
| /start | Ботни очиш, сақланган сўровномани давом эттириш |
| /new | Янги сўровнома |
| ⬅️ Орқага | Аввалги саволга қайтиб тузатиш |
| ❌ Бекор қилиш /cancel | Фақат жорий қораламани ўчириш |
| ✅ Расмлар тайёр | 5–6 та фотодан кейин текширишга ўтиш |
| 📨 Бошқармага юбориш | Маълумот ва фотоларни бошқармага юбориш |
| /status | Охирги юборилган сўровнома ҳолати |
| /chatid | Созлаш учун чат ID рақамини олиш |

Текшириш босқичидан «Орқага» босилса, фотолар қайта танланади. Бекор қилинган қораламалар ўчади; аввал юборилган сўровномалар бекор қилинмайди.

## Файллар ва ишончлилик

`.env` — бот токени ва қабул қилувчи гуруҳ ID рақами; оммага чиқарилмасин. `data/bot.sqlite3` — қораламалар, сўровномалар ва юбориш навбати. Резерв нусха учун ботни тўхтатиб, `data` папкасини кўчиринг. Фотолар Telegram file_id орқали сақланади ва шу бот орқали қайта юборилади; алоҳида офлайн фото архиви яратилмайди.

Юбориш босқичлари алоҳида сақланади: масалан, фотолар етказилмаса, аввал етказилган матн одатда қайта юборилмайди. Telegram хабарни қабул қилган, лекин тармоқ узилиши сабабли жавоб келмаган ҳолатда такрорий хабар бўлиши мумкин. Барча материаллардаги сўровнома рақами уларни ажратишга ёрдам беради. Бир токен билан бир нечта жараённи бир вақтда ишлатманг.

Қабул қилувчи гуруҳни алмаштирганда навбатдаги сўровномалар янги гуруҳга боради. Гуруҳда Telegram topics ишлатилса, хабарлар умумий мавзуга тушади; алоҳида мавзуга юбориш бу версияда созланмаган.

## Синов

`python3 -m unittest -v test_bot.py` — Telegramга уланмасдан, сохта API билан жараёнларни текширади. Ҳақиқий токен ва гуруҳ бўлмагани учун жонли Telegram юбориши тўплам тайёрланганда текширилмаган.

Telegram расмий Bot API маълумоти: https://core.telegram.org/bots/api
